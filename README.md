# Rare Disease, Real Kid: MVA Hackathon 2026 — Track 1

Variant prioritization pipeline for Track 1 (rank candidate causal variants from the organizers' WGS VCF, GRCh38).

All code, configuration, pre-registration records and documentation are in [`track1/`](track1/).
Start with [`track1/README.md`](track1/README.md): it describes the two ranking routes, the data boundary,
the folder layout and the run order.

| Path | Contents |
|---|---|
| [`track1/README.md`](track1/README.md) | Method overview, data boundary, layout, run order |
| [`track1/docs/`](track1/docs/) | Methods file, filled methods form, pre-registration records |
| [`track1/config/`](track1/config/) | Pre-registered ranking rules and Phase 2 protocol |
| [`track1/scripts/`](track1/scripts/) | Pipeline steps 00–10 |
| [`track1/benchmark/`](track1/benchmark/) | Generalisation benchmark on public genomes |

No patient data is stored in this repository.

The state of the repository at the submission deadline is tagged
[`track1-submission`](https://github.com/Vero79L/mva-hackathon-2026-track1/releases/tag/track1-submission). This README was added after the deadline as a
pointer only; it changes no code, rule or result.
